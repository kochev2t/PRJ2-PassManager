# Менеджер паролей (Python + SQLite3 + Fernet)

Локальное CLI-приложение для хранения логинов и паролей. Все записи лежат в базе
SQLite3, пароли шифруются через `Fernet` из библиотеки `cryptography`.

## Особенности

- **Мастер-пароль.** При первом запуске приложение запрашивает его дважды и сохраняет
  в отдельной таблице `master_password` в виде хеша `SHA-256(соль + пароль)`.
  Открытый мастер-пароль в базу не попадает. При последующих запусках он требуется
  для входа; ввод скрыт (`getpass`).
- **Шифрование.** Пароли записей шифруются ключом Fernet из файла `.key` рядом со
  скриптом. Если файла нет — он создаётся автоматически при первом запуске.
- **SQLite3.** При старте проверяется наличие таблиц; при необходимости они создаются.
- **Генератор паролей.** Длина по умолчанию 16 символов. Настраиваются строчные и
  заглавные буквы, цифры и спецсимволы; из каждого включённого набора гарантирован
  минимум один символ.
- **Два режима.** Команды CLI для скриптов и интерактивное меню, если запустить
  приложение без аргументов.
- **Копирование в буфер обмена.** Скопировать пароль можно командой `copy`,
  флагом `get --copy` или пунктом 6 меню.

## Установка

Нужен Python 3.9 или новее.

```powershell
python -m pip install -r requirements.txt
```

Файл `requirements.txt` содержит единственную зависимость — `cryptography`.

## Первый запуск

```powershell
python password_manager.py
```

или любая команда, например `python password_manager.py list`. При первом запуске
появится приглашение:

```
Первый запуск: создаём мастер-пароль.
Придумайте мастер-пароль:
Повторите мастер-пароль:
```

После этого создаются файлы `vault.db` (база) и `.key` (ключ шифрования).
При каждом следующем запуске достаточно ввести мастер-пароль один раз.

## Интерактивное меню

Запуск без аргументов открывает меню после успешной аутентификации:

```
=== Менеджер паролей ===
1. Добавить пароль
2. Получить пароль
3. Список записей
4. Удалить запись
5. Сгенерировать новый пароль
6. Скопировать пароль в буфер обмена
0. Выход
```

Пункт 5 спрашивает длину и наборы символов, показывает сгенерированный пароль
и предлагает сразу сохранить его под указанными названием и логином.

## Команды CLI

| Команда | Назначение | Пример |
| --- | --- | --- |
| `add` | Добавить запись | `python password_manager.py add Google user@gmail.com` |
| `get` | Показать логин и расшифрованный пароль | `python password_manager.py get Google` |
| `list` | Список названий и логинов | `python password_manager.py list` |
| `delete` | Удалить запись | `python password_manager.py delete Google` |
| `new` | Сгенерировать пароль | `python password_manager.py new --length 20` |
| `copy` | Скопировать пароль в буфер | `python password_manager.py copy Google` |

У `add` пароль можно передать третьим аргументом, но лучше оставить поле пустым —
тогда он будет запрошен скрытно. Названия записей нечувствительны к регистру
(`Google` и `google` — одна запись).

Примеры генерации:

```powershell
# 16 символов со всеми наборами (по умолчанию)
python password_manager.py new

# 20 символов, только буквы и цифры, сразу сохранить
python password_manager.py new --length 20 --no-special --add --title GitHub --login octocat

# сгенерировать и скопировать в буфер обмена
python password_manager.py new --copy
```

## Как копировать пароли

Скопировать расшифрованный пароль в буфер обмена можно тремя способами:

```powershell
python password_manager.py copy Google     # отдельная команда
python password_manager.py get Google --copy
```

...или выбрать пункт 6 в интерактивном меню и ввести название записи.

Приложение использует системную утилиту без дополнительных зависимостей:

| ОС | Утилита |
| --- | --- |
| Windows | `clip` |
| macOS | `pbcopy` |
| Linux | `wl-copy`, `xclip` или `xsel` |

Если подходящей утилиты нет, пароль просто выводится в терминал — его можно
выделить и скопировать вручную.

## Файлы приложения

Рядом с `password_manager.py` создаются:

- `vault.db` — база SQLite3 (таблицы `master_password` и `passwords`);
- `.key` — ключ Fernet.

Если в папке осталась база от предыдущей версии (таблицы `meta` и `entries`),
при следующем запуске данные автоматически переносятся в `master_password` и
`passwords`, а старые таблицы переименовываются в `meta_legacy` и `entries_legacy`.

**Сделайте резервную копию обоих файлов.** Потеря `.key` означает, что
расшифровать сохранённые пароли будет невозможно.

## Замечание о безопасности

Хеширование через SHA-256 с солью реализовано по требованиям задания. Для реальной
защиты мастер-пароля лучше использовать специальные функции:
PBKDF2-HMAC-SHA256, bcrypt или Argon2id — они намеренно замедляют подбор пароля.

## Структура кода

В `password_manager.py` четыре класса:

- `DatabaseManager` — создание БД/таблиц, установка и проверка мастер-пароля,
  операции с записями (`add_password`, `get_password`, `list_passwords`,
  `delete_password`);
- `EncryptionManager` — загрузка/создание `.key`, `encrypt`, `decrypt`;
- `PasswordGenerator` — генерация пароля по выбранным наборам символов;
- `PasswordManager` — взаимодействие с пользователем: `setup_master_password`,
  `authenticate`, `add_password`, `get_password`, `list_passwords`,
  `delete_password`, `generate_password_interactive`, `show_menu`.
